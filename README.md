# DesignFox POS Systems

A modern Point of Sale and Invoice Management system built for **DesignFox Pvt Ltd** - a creative agency specializing in Graphic Design, Web Design, and Digital Marketing.

## Features

- **Dashboard** - Overview of revenue, pending payments, total invoices and clients
- **Invoice Creation** - Create professional invoices with pre-defined services
- **Invoice Management** - View, edit, filter, search, and delete invoices
- **Client Management** - Maintain a client database with contact details
- **Print / PDF** - Generate printable invoices with company branding
- **Status Tracking** - Track invoices as Paid, Pending, Overdue, or Draft
- **Local Storage** - All data persisted in browser's localStorage

- No external dependencies required
- Responsive design for all devices
- Modern UI with Inter font family

## Getting Started

Simply open `index.html` in any modern web browser. No build step or server required.

## Usage

1. **Add Clients** - Go to Clients page and add your client details
2. **Create Invoice** - Click "New Invoice", select client, add services and amounts
3. **Manage Invoices** - View all invoices, filter by status, search by client
4. **Print/Download** - Open any invoice and click "Print / Download" for a printable version
